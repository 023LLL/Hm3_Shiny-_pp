# TB NanoString Shiny App
This app performs k-means clustering on TB NanoString data using PCA, UMAP, and NMF.

## Required packages
install.packages(c("shiny", "uwot", "NMF", "mclust"))

## How to run the app

1. Download app.R and TBnanostring.rds.
2. Save both files in the same folder.
3. Open app.R in RStudio.
4. Click Run App.
